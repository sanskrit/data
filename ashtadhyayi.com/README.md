Data from ashtadhyayi.com
=========================

Upasarga data from [ashtadhyayi.com][data].

[data]: https://github.com/ashtadhyayi-com/data/tree/master


### `upasargas.csv`

(Headers: `group,dhatu,code`)

Combinations of upasargas and dhatus from the Upasargarthacandrika.

- `group` is a list of upasargas separated by `-` characters.
- `dhatu` is the dhatu's text.
- `code` is the dhatu's code on [ashtadhyayi.com](https://ashtadhyayi.com),
  which is consistent with the coding used by `vidyut-prakriya`.

All upasargas have their normal forms, but `A` is rendered as both *A* and *AN*.
